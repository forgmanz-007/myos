# Windows-style extra apps (File Explorer, Terminal, Snipping Tool, Notepad, ...)
Keywords: file manager, file explorer, explorer, terminal, command prompt, cmd, screenshot, snipping tool, print screen, notepad, text editor, calculator, photos, image viewer, pdf, zip, archive, win+e

This system ships with few apps on purpose. install_app understands these everyday names
(e.g. install_app "File Explorer"), or install them as admin with apt-get install -y PACKAGE:
| Windows | Package | Shortcut after install |
|---|---|---|
| File Explorer | dolphin | Win+E |
| Command Prompt / Terminal | konsole | Ctrl+Alt+T |
| Snipping Tool / Print Screen | kde-spectacle | PrtScn, Win+Shift+S |
| Notepad | kate (or kwrite) | |
| Calculator | kcalc | |
| Photos | gwenview | |
| PDF reader | okular | |
| 7-Zip / WinRAR | ark | |
| Disk Management | partitionmanager | |
| Paint | kolourpaint | |
After installing, the app appears in the Start menu.
Task Manager is built in (Ctrl+Shift+Esc): do not install one.
